# CI-CD-Projekt

Detta repository visar en grundläggande pipeline för Continuous Integration och Continuous Deployment. Projektet är utformat som en basstruktur för automatisering och pipeline-arbete.

---

## 🛠 Funktioner

- Automatiserad bygg (build) och test-körning  
- Deployment-förberedelser (t.ex. staging/miljö-konfiguration)  
- YAML/konfigurationsfiler för CI-verktyg
